# 大肥鱼 · 个人 QQ

使用 SnowLuma + QQ Bridge + DeepSeek Harness，保留个人 QQ 聊天、QQ 收藏表情、AI 记忆和管理界面。旧腾讯官方 QQBot 及其历史数据、回退备份已移除。

后续整改设计见 [统一优化方案（待实施）](docs/optimization-plan.md)。该文档描述计划中的改动，不代表当前代码已经实现；修改与测试分别按管理员指示进行。

## 一键启动

双击根目录 **`一键启动.vbs`**。也可以执行 `npm run bridge:start`。

入口会打开管理页，并依次启动已安装的 QQ、SnowLuma、DSH 和 QQ 桥接，等待各服务就绪；已运行的服务会复用。SnowLuma 启动时启用其自动发现接入功能，桥接只接受配置中的目标 QQ 身份；如需关闭自动接入，可在本机桥接配置设置 `bigfatfish.startup.autoHook: false`。首次协议确认、QQ 扫码或验证仍需在界面完成，不会保存或自动输入 QQ 密码。

管理页可以一键启动、停止、重启全部组件，或单独操作网关、DSH、桥接。“停止全部”保留管理页，不退出 QQ。通过其他入口启动的进程只复用，不强行结束。页面区分服务已监听、QQ 登录身份已核验及账号在线；真实消息收发仍需在测试会话验证。

- 管理页：`http://127.0.0.1:3105/`（从一键启动进入会自动完成令牌验证）。
- QQ 接入与登录：`http://127.0.0.1:5099/`，也可点击管理页的“QQ 接入 / 登录”。
- 桥接控制台：`http://127.0.0.1:3106/`，从管理页进入。
- DSH：`http://127.0.0.1:3086/`。

## 话题学习、定时和主动聊天

在 QQ Bridge 控制台侧边栏的主动策略页面调整；保存立即生效。系统从各会话真实聊天中发现反复出现的词组，达到讨论门槛后自动加入该会话的话题兴趣，再聊到时按60%提供参与机会；不再用预设词的0至100分决定动态接话。真实 @ 和明确称呼仍优先。

## 管理页入口

本地新增功能已直接并入 QQ Bridge 原管理网页（`http://127.0.0.1:3106/`），总览提供快捷入口，原来的右下角悬浮设置窗已移除。

- **会话与审批**：添加群聊、添加私聊，按群号 / QQ 号启用或停用参与，处理已收到的好友申请与群邀请。启用名单不会代替实际加群或加好友。
- **人格与角色**：人格列表旁“＋ 新增人格”打开原编辑器；列表用于编辑模板。“按群聊 / 私聊选择人格”通过下拉框为每个会话单独选择已创建的模板，选择后立即保存，从下一轮对话生效。可选“跟随全局默认”或“本会话不使用人格模板”；全局默认也通过已有模板下拉选择并应用。模板改名会同步会话绑定；删除后受影响会话恢复跟随默认。编辑模板正文会沿用原接口更新，切换不清空会话记忆或更改参与名单。
- **话题与主动策略**：自动话题门槛、各会话的热话题及来源消息数、定时、主动额度和无回应退避。
- **长期记忆**：按会话搜索、添加、纠正和删除事实，编辑摘要，控制记忆积累与使用。
- **统一风格学习**：融合允许学习的真人表达，所有会话共用一份风格；查看依据、设置学习门槛、锁定、删除和回滚。
- **黑话词库**：新增评分、自动入库策略、未达标原因和入库记录；下方保留原候选审核与释义研究。
- **调试与运维**：本机服务状态、启动全部、单独服务操作、独立语音入口。停止或重启桥接仍从独立启动管理页执行，保证停止后有入口重新启动。

## 聊天黑话评分与原词库联动

沿用原 `slang` 词库和人工研究入口。消息计数与评分在本地计算；达标后的语料研究会请求模型。词条只存入原 `state/slang.json`，不另建黑话词库。滚动学习记录独立于聊天上下文，每会话最多10000条；保留时长取各学习模块所需窗口的最大值，默认因统一风格保留30天。话题、黑话仍按各自的近7天窗口分析，私聊不进入群话题或黑话研究。

**进入候选的门槛**：管理页“黑话词库 → 聊天黑话 · 评分与自动入库 → 进入候选至少真人消息数”可设置1至100条，默认3条。自动提取和 AI 提交的新词，须在回看时长内保留的已启用群聊记录中，出现在足够多条不同真人消息里，才写入候选库；跨群累计，同一条消息重复提词、AI 重复提交、机器人发言均不增加条数。未达标的 AI 提交返回 `status=pending` 及当前/要求条数。已有词条保留，人工添加不受此门槛限制；进入候选不等于确认可用于聊天。

评分由真人消息频次（30分）、不同发言者（20分）、使用时间跨度（15分）、释义完整性（20分）和近期使用（15分）组成。候选达到4条真人消息、2位发言者后自动研究含义。默认确认要求至少80分、4条真人消息、2位发言者、30分钟跨度，并且研究通过、有可用释义、无待审核风险；每日最多自动确认20条。新自动研究的最低置信度为80%。统计使用独立滚动学习记录，不再仅限聊天上下文的100条。

**本机已按要求启用自动研究和自动确认**。在“黑话词库 → 聊天黑话 · 评分与自动入库”分别管理新候选、研究与正式入库门槛。自动提取和上下文注入仍受原“黑话系统参数 → 启用黑话学习”控制。符合条件的候选变为原词库的“已确认”，供聊天上下文使用。写入失败撤回本次确认，额度跨重启保留。原人工审核入口继续可用。

“话题与主动策略”管理话题研究、滚动记录上限、最低置信度和每日研究额度。默认每5分钟检查一次，每日最多研究30次，失败至少60分钟后重试；“重试失败的研究”可以重新排队失败项，仍遵守额度。研究使用临时独立模型会话，不向QQ发送研究过程；话题只使用本群语料，黑话全局共享。统一风格在独立页面管理，同时计入研究总额度。模型未能确认、来源编号无效、服务或保存失败时，候选不激活。

手动“批量送DSH深度研究”“研究全部候选”和单词条研究统一在黑话页面的 **DSH研究任务与返回** 查看：提交后显示任务号、排队/执行阶段、已处理数量和每批返回摘录；词条展开后显示释义、用法、来源、风险及未确认原因。页面每3秒自动刷新并保留已展开内容。每批最多5词、单批最多等待5分钟，重复提交不会重复排队，DSH离线时立即报错，超时和重启中断都可见。手动研究的模型调用计入每日研究额度；研究通过仍需原正式入库条件，未确认的建议释义保留为查看资料。

管理页显示已纳入和候选话题、研究阶段、学习记录条数、参与人数、最近提及时间和主动检查记录。话题只在本会话使用，不串群；默认90天未再提及后停用。学习与使用遵守记忆开关。候选由重复词组发现，再由模型核对语境；尚不自动合并同义词。独立记录从当前仍保留的消息和后续新消息开始累计，升级前已丢弃的历史不会自动恢复。原兴趣分接口保留兼容旧模式，不作为新版动态话题参与门槛。

最终回答由 **统一全局风格 + 当前角色卡 + 本会话长期记忆** 共同决定。原群风格及会话风格设置已移除；统一学习不复制原句，不将个人经历或私聊事实带到其他会话。具体规则、版本控制与审查说明见 [统一风格自动学习](extensions/bigfatfish/GLOBAL_STYLE.md)。

消息优先在一条里完整表达，一条可以包含多句话；确有内容和节奏需要时再分条，不固定凑两条，也不固定先附和再补充。闲聊字数设置仅作简练程度参考，不作为拆条门槛。

可在“统一风格学习 → 回复分条方式（全局）”切换“自然分条 / 尽量一条 / 适度分条”，保存后即时用于后续回复，无需重启；这是表达偏好，不强制固定条数。

## 记忆机制

- 会话令牌继续隔离群聊与私聊；长期事实和摘要必须引用本会话的真人消息，不能使用模型自己的输出或伪造消息ID作为来源。
- 长期事实按发言者及规范化正文去重，同一来源重复提交不增加确认次数；明确变更偏好时可用 `extra.replaceId` 修正同一人的旧事实。
- 支持置信度、重要度与有效期。默认每会话保留80条事实，每次召回最多8条；按当前话题相关性、重要度、新鲜度和确认次数排序，过滤过期、低置信度与隐私内容。
- 阶段摘要默认最多3000字并保留来源；待说想法默认2小时过期，活跃话题24小时过期。临时讨论和玩笑不自动认定为长期事实。
- 长期事实和摘要由现有会话工具更新，提示词要求只提取真人明确的偏好、约定及未完成事项；原始聊天不直接堆入长期记忆。

## 心情与记忆增强（2026-10-24）

侧栏新增“鱼的心情”：按群聊或私聊独立维护心情、七项情绪、自然回稳和判断记录，可选择只展示或影响后续一轮闲聊。默认关闭，按会话启用后才调用模型；默认每会话每日12次、全局40次，支持关闭、重置及可信度门槛。

“长期记忆”支持稳定事实/事件分类、按发言者隔离的事实键、检索词、旧版本恢复、档案预览导入和召回原因。模型新增记忆默认每天8条；管理员导入不占该额度。记忆和心情都沿用现有会话隔离；主动聊天支持可编辑的开场动机，保留现有调度与额度。

使用与边界见 [心情与记忆增强](extensions/bigfatfish/COMPANION.md)。重启桥接并刷新管理页后生效。本次只做两模块定向测试与离线控件验证：`npm run test:companion`；未做全量审计或真实QQ/模型联调。

## QQ 收藏表情与语音

收藏表情通过 QQ 接口同步、收藏、备注和发送，不维护本地表情库。收藏发送携带 OneBot `sub_type=1` 和动画表情摘要，安全下载后的原始图片/GIF字节保持不变；收藏ID不冒充商城表情ID。动图仍由既有媒体处理流程处理，临时处理不等于本地素材收藏。

独立 voice-tool 尚未安装；取得后通过本机配置 `bigfatfish.voiceToolDir` 指定真实工具目录。未安装时界面显示不可用。

## 随机主动与消息队列

“话题与主动策略”新增聊天中随机主动：在未安排正常回复、没有明确待答消息的群聊合并轮次中，以18%概率尝试围绕近期上下文分享。默认两次尝试至少间隔5分钟，沿用静默时间和主动额度，不受冷场演练/冷场时长限制。管理页可开关和调整概率，并查看待处理、明确待答、处理游标及近期发送记录。队列及冲突规则见 [接话与随机主动](extensions/bigfatfish/PARTICIPATION.md)。

## 模型与 API 池

QQ Bridge 管理页侧栏“模型与 API 池”可新增、编辑、停用、删除接口及其密钥，运行内部连通性测试，并手动选择当前使用的接口。每个条目对应一个接口、模型与独立密钥；可保存最多50个条目，暂未填完接口或模型的条目作为草稿保留。切换后下一次模型请求生效，已有会话记忆和人格不变，进行中的回复继续完成；没有自动轮换或自动回退。

连接测试会先进行无密钥的访问条件检查；学校接口明确返回“仅限校内访问”时，显示需连接校园 VPN 及对应 HTTP 状态，不再只提示笼统的连接失败，也不继续消耗模型测试请求。普通未鉴权、无模型列表或未知网络响应不会替代真实模型测试。接口切换仍由管理员决定，不自动改用其他接口。

支持 Chat Completions、Responses、Anthropic Messages 三种协议。基址填写例如 `https://token.nuaa.edu.cn/v1`，不包含操作路径；模型名称按服务商实际 ID 填写。图片能力和思考档位按接口真实支持情况选择。密钥通过 DSH `credentials` 接口写入 `data-bridge/.credentials.yaml`，API 池状态文件只存元数据，不向浏览器回传密钥；编辑留空保留原密钥，删除条目同时删除该条目的凭据。当前条目需先切换后才能删除或停用。

内部测试不发送 QQ 消息，不会把被测试的接口设为当前接口；测试完成后恢复该测试引起的 DSH 全局默认模型变化。模型选择失败时停止该次中转请求，避免继续使用旧模型。接口列表和操作仅向管理端开放，不允许会话工具访问；保存和删除带版本检查，防止覆盖其他页面的修改。

聊天、话题、风格、心情和黑话研究共用当前模型选择。联网搜索仍为独立配置，普通聊天中转不等于提供原 DeepSeek 服务端搜索；原用量页费用为内置价目估算，中转实际费用以平台账单为准。

当前按用户选择继续使用 DeepSeek 官方直连；南航 Token 条目及凭据已保存但未启用。2026-10-24 从本机访问南航 `/models` 和 `/chat/completions` 均返回 HTTP 483“访问被禁止”，暂不能确认模型可用，需平台允许访问后重新测试。DSH 本地桥接地址继续为 `http://127.0.0.1:3086`。

## 配置与维护

当前群聊策略：普通旁观接话40%，已经参与话题后的接话60%，命中已学话题的接话下限60%；“肥鱼”“古月方鲸”等明确称呼与真实 @ 优先。管理页“话题与主动策略”可编辑学习门槛、称呼和接话概率，查看各会话学到的话题，并从已有消息重新发现。动态接话只抽样一次，不用旧分数追加强制唤醒。开启“群聊确认在跟机器人说话才回答”会限制自动插话；需要话题参与时保持关闭。无关话题仍按退火策略降低参与，原显式关键词订阅仍有效。

- QQ账号、管理员、参与名单与接口令牌：`integrations/qq-bridge/config.json`。
- 人格、行为设置和当前记忆：`integrations/qq-bridge/roles/`、`integrations/qq-bridge/state/`。
- DSH 当前配置与会话：`data-bridge/`；运行日志：`logs/bridge/`。
- 定制代码：`extensions/bigfatfish/`；可重复应用的上游补丁：`scripts/apply-bridge-extension.cjs`。
