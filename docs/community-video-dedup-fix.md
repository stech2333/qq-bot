# 社区重复视频处理修复

2026-10-29。

本地 25 条材料的视频 ID 没有重复行。日志中重复出现同一视频，既包含正常的字幕/评论续读，也暴露出批次末尾才提交进度的问题：后续材料失败时，前面已读取的片段再次进入处理流程。评论分页没有推进、返回空页或重复页时，也可能迟迟不能结束一个视频。

修复范围：

- `community-learning.mjs`：每个片段独立提交知识、候选与读取检查点；后续失败保留此前成功进度。复用缓存时记录 `READ_CHECKPOINT_REUSED`，续读日志包含阶段、偏移、回复线程和页码。相同评论页跳过模型并结束本轮评论遍历，相同回复页仅结束对应线程，保留其他未读线程；相同字幕段落仍推进偏移，不跳过后续字幕。
- `community-store.mjs`：标题或评论数变化不使已完成视频重新入队；重新发现不清除失败退避。显式保存分页结束的 `null`，避免恢复旧游标。逐片段事务累加发布统计，整个短任务完成后才标记任务结束。
- `community-platforms.mjs`：评论游标未推进或空页不继续循环，尚未读取的回复正常完成后结束；旧记录有字幕偏移而无游标时使用现有偏移续读。
- `community-video-dedup.test.mjs`、`community-conversion.test.mjs`：覆盖后续失败、断点恢复、重复发现、重试退避、分页重复/空页及统计累加。
