# QQ 黑话自动入库与图片输入修复

按本轮要求，QQ 黑话走“聊天候选 → 自动研究 → 直接写入统一公共黑话库”，无需管理员送研究、打分或确认。研究结果用于所有已允许会话，不再按原群限定正式词义。

统一存储仍为 `community.sqlite`。研究输出完成后直接保存正式词义，移除统一库路径上的第二次评分、入库次数配额、手动确认和额外公开 URL 审核。来源消息仅保留追溯引用，不转存聊天正文。个人信息、私人关系和无法形成通用释义的结果不发布。研究结果的真实 confidence 保留，不因入库而抬高。

自动研究在任务调度中优先处理 QQ 黑话；保留现有研究费用保护、停止开关和失败自动重试。当天研究额度不足时自动等待恢复，无需人工重新送研究。外部社区持续学习开关保持原状。

管理界面删除原黑话操作页、确认弹窗、手动添加/研究/批量确认、评分表单和对应事件处理，只在“社区学习与知识”显示只读自动进度及统一知识记录。必要的知识撤销入口保留。

图片问题找到的具体配置错误：当前 API 池活动条目为 `deepseek-flash`，`vision=false`，生成给 DSH 的输入能力因此只有 text。已通过原管理 API 将同一条目的 vision 改为 true；模型、供应商、密钥和费用设置保持不变，原 API 池元数据已备份。不发起真实模型测试，不向 QQ 发送测试消息。

同时更新 `qq_slang_submit` 的工具说明和聊天行为提示，去除“提交管理员筛选”等过时描述。部署时重启 DSH 和桥接以加载工具说明与图片输入能力，QQ 网关保持运行；依用户此前要求不做重启后的重复验收。

新增 `qq-auto-learning.test.mjs` 覆盖直接跨群入库、无需二次审批和私人事实不发布；本轮不重复运行此前测试套件。图片实际模型识别效果未以额外调用验证。
