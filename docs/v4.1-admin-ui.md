共用页面切换函数发出只用于前端的页面事件，点击子导航、搜索、直接Hash、刷新以及历史前进/后退使用同一路径。进入社区页读取状态，离开或文档隐藏时停止社区定时轮询，回来恢复监控。页面切换不向后端发送停止指令，后台学习保持原有运行状态。未保存配置和来源草稿保持挂载，不因轮询或页面切换覆盖。

保留五平台即时开关、真实连接/授权状态、最近学习时间、已完成数量与错误；保留开始/停止、连接检查、立即调度、取消、请求/短任务/持续会话/今日用量、费用、增量日志、来源、任务、学习目标、知识分页、撤销、重试和备份。

## 参数布局和推荐配置

常用区展示今日费用保护、会话费用保护、输入费率、输出费率、单次输出上限，各参数有中文说明。高级 Token 与技术保护默认折叠，保留三个每日Token阈值、请求/短任务超时、UTF-8上下文字节、发现/任务间隔、异常重试、熔断及退避。可空保护仍以空白保存为`null`，明确填写`0`仍是数值零；其他数值按范围保存，必填技术参数与范围错误在提交前由表单验证。

推荐配置包括当前配置、DeepSeek Flash 示例、DeepSeek V4 Pro 示例。仅选择名称不会改变草稿；点击应用只填入费用/Token示例字段，不自动保存、开始或改变实际模型。可撤销最近一次推荐填入，非费用草稿保持编辑状态；应用后仍需保存。Flash按本次要求提供费用保护2/1元、费率2/8元每百万Token、单次输出1600和空的每日Token阈值。这是配置示例，不保证适用于所有代理、模型或计费时段。没有已核实的当前供应商V4 Pro报价，因此Pro示例不写死费率，应用后留空并要求管理员填写。

费用说明提供 `(10000 × 2 + 2000 × 8) / 1000000 = 0.036 元`，注明实际账单、缓存、预留和取消后的可能费用。推理Token包含在输出中，不重复计费。不引入实时价格查询或修改后端计费。
