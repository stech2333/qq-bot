# BigFatFish V4.1 持续社区学习

以 `codex/v4-community-learning` 的 `f756310acacc8202d5f6f127c3469ec26e77fa5f` 为基线，保持原 QQ Bridge、DSH、API Pool、角色、私人记忆与发送事务。本文替代 V4 开发说明中有限轮次、每日8次、固定2/4条和 Schema v2 的相关配置说明。

## 启停和持续运行

“记忆与学习 → 长期记忆 → 社区持续自主学习”保留六个主导航。开始自动保存当前主题和费用参数，检查模型、许可和实际来源能力。至少一个启用来源检查成功即可开始，其余失败来源保留错误状态。没有来源时拒绝启动并记录原因。平台复选框立即保存，只影响后续读取；编辑中的主题、预算和来源表单不会被轮询覆盖。

开启后持久化学习会话，单并发运行短任务。任务完成后自动继续队列或下一页；无新内容进入 WAITING，在来源刷新间隔后继续检查。不会因为学习8条、8轮、模型选2条或短任务超时而结束整个会话。内部批大小按上下文保护裁剪，批大小不是总学习数量限制。主题用于模型排序和探索，不再要求标题包含“互联网文化”等原文。

停止关闭持久开关、取消在途请求、保留检查点并阻止旧结果发布；已提交知识和用量保留。单独取消短任务不关闭持续会话。进程重启保留原会话累计和材料检查点，中断任务重新排队；保护暂停需检查原因并重新开始。正常 QQ 忙时等待，不占用发送队列。

源失败使用指数退避，达到重试保护停止自动尝试该源，其他源继续。页面“恢复该来源重试”清除该源错误计数，保留已完成指纹。模型连续异常触发会话 PAUSED；费用或 Token 保护触发 PAUSED，不伪装成完成。修改保护参数或重新开始后可继续。

## 平台入口和许可

| 平台 | 本次代码能力 | 当前真实连接 |
|---|---|---|
| B站 | Polylens MCP stdio 只读工具白名单，登录检查、搜索分页、jq 字段裁剪、字幕分段、评论和回复分页 | 未配置登录及数据许可，未真实验证 |
| 贴吧 | 独立 Python worker 调用 aiotieba 的 get_threads/get_posts/get_comments，保留帖子/楼层/回复关系与分页 | 未安装/配置授权客户端，未真实验证 |
| 知乎 | 授权文件、Feed及可扩展 readonly-json 驱动契约 | 没有内置 zhihu-mcp 的原生协议转换，不宣称已连接 |
| 小黑盒 | 授权文件、Feed及可扩展 readonly-json 驱动契约 | 未确认可用官方/授权读取接口，直接接入不可用 |
| 虎扑 | 授权文件、Feed及可扩展 readonly-json 驱动契约 | 未接入含互动/画像的现有 CLI，不宣称原生读取可用 |

每个来源必须分别填写读取、保存和 AI 学习许可、依据及有效期。平台开关不会授予权限。只有实际能力检查通过的来源才显示 READY；新配置显示待检查或不可用。授权 Feed 的 READY 指该 Feed 读取成功，来源表中仍明确标注 Feed，不冒充平台登录读取。

“继续读取来源/平台开关”控制新任务；`allowUse` 控制历史知识检索；撤回保存许可或许可过期则清理来源正文、候选和证据，撤销失去证据的知识。三者语义独立。关闭当前平台会取消它的活动任务，关闭其他平台不会取消正在处理的来源。

## 本地连接器配置

在桥接运行目录的 `state/community-connectors.json` 配置，仅管理员本机文件可指定可执行程序，页面和模型不接受执行命令。以下路径是示例，必须替换为真实安装路径：

```json
{
  "bilibili": {
    "platform": "bilibili",
    "driver": "polylens",
    "command": "C:\\tools\\polylens-bilibili-mcp.exe",
    "args": [],
    "minRequestMs": 2500
  },
  "tieba": {
    "platform": "tieba",
    "driver": "aiotieba",
    "command": "C:\\tools\\tieba-env\\python.exe",
    "args": [],
    "credentialRef": "QQ_COMMUNITY_TIEBA_BDUSS",
    "minRequestMs": 2500
  }
}
```

Polylens 和 aiotieba 需管理员独立安装；本项目不会自动下载或执行第三方安装器。Polylens 正常登录在其自己的客户端完成，凭据留在其缓存，BigFatFish 只调用登录状态和内容只读工具，不调用登录、点赞、评论等动作。贴吧凭据由指定环境/DSH命名引用读取，仅注入 worker 的 `QQ_COMMUNITY_CREDENTIAL`；没有凭据的公开读取也需实际检查成功和数据许可。源的“探索入口”在 B站表示搜索关键词，在贴吧表示吧名。未填可用入口不得显示已连接。

Polylens 接口按所核对的 server.py 契约调用；任何协议变更导致明确错误及退避，不猜测其他写工具。每次内容工具都使用固定 jq 投影，在返回前裁剪字段，不传作者资料或完整平台响应给模型。字幕、主评论和楼中回复分阶段分页；正文超过单次保护会报错保留进度，不把截断误当完成。

扩展驱动使用 `driver: "readonly-json"`，每次启动配置的固定程序，stdin 传一行 JSON：`{action:"probe"|"discover"|"read",platform,target,...}`。probe 返回 `{ready:true}`；discover 接收 `cursor/topics/goals`，返回 `{items:[{id,title,summary,url,publishedAt,revision}],cursor,hasMore}`；read 接收 `id/cursor`，返回 `{text,readCursor,complete}`。每页正文最多16000字符，列表最多100项；必须保留真实平台链接。错误返回 `{error:"AUTH"|"RATE_LIMITED"|"UNAVAILABLE"|"NETWORK"}`。凭据和原始 stderr 不返回管理端。驱动必须由管理员审阅并具备所需数据权限；通用契约本身不能证明任何平台已接通。

## 队列、恢复和知识

Schema v3 在原 SQLite/FTS5 上增加会话、材料队列、来源状态、学习目标、用量会话索引、日志上下文与规范化词条索引。升级前备份。V4 的 documents 完成标记可能覆盖未读候选，因此迁移保留原知识/证据/预算，清空不可靠的旧完成标记并重置发现游标，再安全去重发现；重复证据不会重复增加知识版本。原 QQ JSON 不迁移。

发现候选和推进发现游标在同一事务内；每份材料独立保存指纹、来源、发现时间、状态、阅读偏移/分页游标、提取结果、已批准候选、错误次数和重试时间。短任务发布只提交实际处理的材料片段。未选择或未读材料仍在队列；长正文需要读完所有片段才 COMPLETED。重启使用已保存的提取/验证结果，避免重做已确认阶段；远端已计费但响应或检查点未保存的请求无法保证恰好一次，预留保留并显示未知，不声称无需重试费用。

规范化词条查询覆盖全部已发布知识与待验证候选，不使用最近100条展示列表判冲突。词义冲突、多义黑话和时效知识再次校验真实引文及语境；低置信和未批准内容留待验证并形成有来源的轻量目标。候选不能以个人主观看法冒充公共事实。时效字段到期后不再检索。没有向量服务或多Agent规划器。

一般表达策略仍是现有安全枚举。经过验证并积累至少3份独立文档、跨至少2天的证据后，由现有 GlobalStyle 的策略入口巩固应用，不另建正式风格管理器或复制到第二份权威库；许可或历史应用被关闭后立即停用关联表达。群聊共享通用知识和表达，私人事实仍按原会话边界读取。

## 监控 API 和用量

沿用管理员鉴权、CSRF及 agent 拒绝规则，路径保持 `/api/bigfatfish/community`：

- GET `?view=status`：轻量会话、短任务、平台状态、计数和目标。
- GET `?view=usage`：当前/最近请求、短任务、持续会话和今日累计。
- GET `?view=logs&since_id=N`：按 ID 递增返回最多100条、游标、hasMore、日志裁剪后 reset 标记。
- GET `?view=knowledge&offset=N&limit=20`：按需分页知识和有限来源链接。
- GET `?view=details`：按需来源及最近短任务；无参数快照仅用于初次加载和手动刷新。
- POST：start/stop/cancel/run/probe/source/retry/revoke/backup。

页面每秒只轮询状态、用量和日志增量，保留正在编辑的表单。日志最多2000条，显示最近100条，包含时间、平台、会话、任务、阶段、级别、原因与数量；不保留原始推理、密钥、Cookie或完整模型响应。数据库故障不影响原聊天上下文。

实际 usage、未结算预留和流式输出估算分开展示；供应商返回 usage 后结算，即使正文验证失败也保留已知消耗。推理包含在输出中，不能再次相加。没有 usage 的失败或取消请求仍占费用预留，显示未知及请求终态；不会虚构真实Token或账单。今日/会话阈值可留空，但模型费率上界、输出/上下文限制、超时、单并发、退避和异常熔断保留。
