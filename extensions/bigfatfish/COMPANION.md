# 心情与记忆增强

2026-10-24 在现有 QQ Bridge 上实现。功能设计参考 [鱼的记忆](https://github.com/Yuuyuko-uu/dsh-fish-memory)、[鱼的心情](https://github.com/Yuuyuko-uu/dsh-feiyu-mood)、[主动搭话](https://github.com/Yuuyuko-uu/dsh-speak-up)；没有安装这些插件，没有接入朗读桥。QQ 收发继续沿用当前桥接的会话映射、发送工具和权限检查。

## 管理入口

代码和补丁已经更新。重启桥接并刷新原管理控制台后，使用侧栏“长期记忆与风格”和“鱼的心情”。本次没有自动重启服务或启用真实主动发送。

## 鱼的心情

每个 `group:群号` / `private:QQ号` 一份状态。选择会话，勾选“启用本会话心情”后保存。默认关闭，启用才会请求模型。支持自动判断开关、仅展示/只说心情/最近感受三种影响方式，伙伴称呼、基线、下限、衰减和判断额度均可调整。

- 只处理二代聊天的实时回合；完成且实际发出了文字才会判断。读取快照、静默维护、学习会话、失败回合不产生判断。
- 判断输入是本会话最近四条合格真人消息和本轮已发送文字，不读取其他会话；主动发言单独标记为角色自主参与。
- 复用现有独立学习会话执行器和模型配置。结果不转发到 QQ。一次判断是一项额外模型请求；默认至少间隔5分钟、每会话每日最多12次、全部会话每日最多40次，北京时间计日。尝试额度写盘后再调用，失败也计入，重置不返还额度。
- 心情0至100，基线70，下限20；心情向基线回稳，默认半衰期12小时。开心、踏实、亲近、心疼、担心、难过、吃醋七项向0衰减，默认半衰期90分钟。数值仅表示角色状态。
- 判断需提供本次真实来源编号。可信度低于默认0.7只留记录、不改数值；显著变化默认至少3点，才可影响下一轮闲聊，最多附加一次。超过两个心情半衰期的旧感受不再附加。正式回答不附加心情。
- 关闭、重置、切换设置、会话令牌变化或撤销参与时，丢弃正在等待的旧结果；模型异常和保存失败不会把新情绪写成有效状态。记录最多40条。
- “允许积累新记忆”关闭会暂停自动判断；“使用长期记忆与动态风格”关闭会停止附加心情。两个开关均不删除已有记录。

状态沿用 `state/social-v2.json` 中会话的 `bigfatfish.mood`，调用额度在 `state/mood-budget.json`。管理 API 为 `/api/bigfatfish/mood`，GET读取，POST `configure` / `reset`，修改需带设置版本；QQ 模型不能调用管理接口。

## 鱼的记忆

- 事件使用原有时间半衰期；标为稳定事实的偏好/约定不衰减。到期与淡忘是两回事，0有效天数表示不设置到期。查看、检索和重复提交同一来源不会强化记忆。
- 中文按 `Intl.Segmenter` 切完整词，过滤常见虚词和泛词；按库内词频计算检索证据，再按相关性、重要度、鲜活度和确认次数排序。无具体证据时不为凑条数注入无关记忆。它仍是词法检索，不能保证理解所有同义改写。
- 召回引用包含事实ID、发言者、时间和类型。默认最多8条、1600字符，稳定事实最多2个名额；可在“话题与主动策略 → 记忆保留与召回”调整证据门槛、字数和每日新增上限。预算包含引用的结构化元数据。
- 模型仍须提供本会话真人来源 `extra.sourceMessageId`。可附加 `factKey`（对象.方面，不含具体值）、`kind`（event/stable）、`tags`（最多8个检索词）。事实键按发言者隔离，同键更新只取代同一人的旧状态；不确定就留空。没有额外的自动扩词调用。
- 修正和事实键更新保留旧版本；超过活跃容量或到期的条目移入历史、不参与召回。历史最多保留200项，可恢复未过期条目或删除历史。恢复同样遵守容量、来源和会话边界；备份仍保持最近5份。
- 默认每会话每天最多新增8条模型记忆。重复来源/重复事实不额外计数；删除和重启不重置当天配额。管理员的核实、纠正和档案导入不占这个模型新增额度。
- “记忆召回与历史”显示最近召回及未选中原因，也可输入一句话进行只读试召回。
- 档案支持选择UTF-8文本文件或粘贴，最多100KB；本地逐行拆为候选，先预览再勾选，明确提交后才写入选中会话。跳过标题、代码块、表格、过长/过短、重复、已有历史和已删除内容。预览15分钟失效，提交检查会话和记忆版本。
- 导入内容标为管理员核实的档案并保存文件名及行号，不伪造群友来源；不会调用模型或扫描磁盘目录。复杂叙事请先整理为每行一件事。删除指纹最多保留1000项，历史和备份均有明确容量边界，不是永久销毁保证。

新增历史、删除指纹、每日写入统计和最近召回记录都沿用原会话状态与备份机制，不建第二个记忆数据库。旧事实默认按事件读取，不自动批量改写。

## 主动参与

借鉴“主动搭话”的自发参与表达，增加“主动开场动机”配置，作为真实冷场回合的表达参考；可留空。原定时器、话题门槛、静默时段、演练、每日额度和无回应退避继续生效。没有叠加第二套随机调度器。
