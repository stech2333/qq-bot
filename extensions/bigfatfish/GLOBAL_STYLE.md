# 四层群聊表达系统

L0 继续使用 `PersonaManager` 的模板原文、按群/私聊绑定和人格签名。可信人格由现有 QQ 预设的 `qq-persona.mjs` 注册为 DSH 会话系统提示段，原文不因风格学习改变。旧人格的发送取消、令牌撤销和历史自身消息过滤继续由原桥接完成。

L1 使用 `state/global-expressions.json` 保存管理员发布的通用策略枚举。没有自动跨群晋升。旧 `state/global-style.json` 原样保留为兼容资料，不再研究或注入，不复制到任何群。

L2 使用 `state/group-styles/<sha256(scope)前24位>.json` 独立保存群画像。包含 scope、schemaVersion、version、revision、features、expressionExamples、evidence、confidence、createdAt、updatedAt、lastLearnedAt、enabled、apply、locked，以及截止时间、删除墓碑、任务代际和最多20版历史。文件名不包含未校验路径。独立原子写入；损坏时只读报错，不以空文件覆盖。

L3 的 `style-resolver.mjs` 本地识别日常、吐槽、技术、求助和结束场景；先限定当前群，过滤已审核、未过期和来源仍有效的经验，再按场景、动作、适用条件、支持分和近期使用情况排序，最多选两条且动作多样化。明确求助和事实准确优先，正式场景排除玩笑语气、表情习惯和闲聊长度参考。未命中时只用人格及必要通用策略。

## 来源、学习与审核

只有真实入站链路标注了 scope 和 sourceVersion=2、具有有效数字 QQ 消息 ID 的真人消息能成为新群风格依据。旧窗口、私聊、机器人输出、转发、引用正文、媒体内容、隐私、链接和敏感指令不进入风格归纳。窗口保留时间和话题/黑话共用底层日志，但新群风格从可验证来源重新开始，不补造旧证据。时间、匿名发言者、明确引用目标和相邻序号用于背景关联，相邻不等于问答。

默认门槛为20条去重消息、3个北京时间自然日、2名发言者；每项至少3条、跨3天及2人证据。相同内容在整个窗口只计一次，每人每分钟最多一条、每天最多12条；抽样按日期和发言者轮询，最多48条。句长中位数、短句比例和标点统计在本地计算。

后台沿用 LearningResearch 单并发、持久化总预算、重试、当前 API 池和临时研究会话；每群默认6小时、每日4次、每轮最多更新2项，语料不足不调用模型。关闭风格学习时后续入站消息不再获得风格来源标记。停止应用不会清队列或删除事实。

模型结果只允许闭合 Schema：特征枚举及经验的 scene/action/structure/strategy/when/avoid/sourceMessageIds/confidence。拒绝多余字段、自由指令、未知枚举、无效来源和证据不足。经验不存原句、个人事件或身份；持久化来源只有作用域内匿名 ID、时间和匿名发言者。模型评分是未经校准的评分，界面支持分另按证据数量、多发言者和多日期计算，不代表正确概率。

自动结果只能是候选。管理员审核后才生效，可编辑策略、锁定、拒绝、删除、回滚。新特征候选不会撤下原已审核特征。人工特征优先，已锁定项不自动覆盖。删除保留墓碑，清空轮换任务代际并设置来源截止时间，旧任务与旧消息不能复活数据。回滚只恢复风格，不恢复消息水位或发送记录。

## 管理与提示词

沿用桥接控制台 `/api/bigfatfish/*` 的令牌、Origin、会话工具禁止访问规则。`group-style` 管理接口带 revision；预览仅做本地解析与排序，不改使用统计或研究额度。学习文本和来源在页面通过 textContent 展示。

`buildWakePromptV2` 只调用一次 `bff.instruction`，由 resolver 组装表达和一份事实记忆。实际投递前将角色卡写入可信会话快照并从用户消息中移除，现有预设插件在每次系统提示组装时读取对应 sessionId 的快照。QQ 普通工具不能访问快照文件。`responseContext` 只返回场景/版本/ID等更新元数据；智能体 get_prompt 不再重复返回角色正文和已注入事实。

诊断给出各段字符数、表达经验 ID、群风格版本、人格签名、重复段标记。`tokens=null` 表示未获得真实 tokenizer 或 usage；不将字节或字符冒充 token。成功发送后更新最近使用时间；预览不影响排名，使用元数据保存失败不触发重发。

黑话继续使用原 `slang.json` 和原候选研究/评分机制。新自动词按 group scope 隔离；public 需要管理员明确确认；shared 只面向管理员逐群独立确认的 confirmedScopes。旧无可靠范围词保留为 legacy，默认不应用。相同词面按 scope upsert，正式求助不强行注入词库。管理员可在群页面确认作用域，原词库页面编辑释义。

## 保留、删除与迁移

原学习日志默认30天、有界10000条；话题/黑话按自己的窗口读取。活跃会话维护时压缩过期日志；停用群日志不再用作学习，本次不会自动删除其磁盘旧文件，管理员可在原目录归档或删除，重新启用时仍按窗口过滤。群风格文件没有聊天流水。自动风格每次应用重新确认来源仍在允许的学习窗口内；过期或群停用后失效。清空群风格会清空风格历史、证据引用和候选，并保留删除截止信息；共用原始日志仍由自身保留策略清理，以免连带删除事实/话题来源。

旧人格、长期事实、旧词库和旧 global-style 文件不自动删除。没有自动将旧跨群结果解释为本群成果。实际运行前管理员需同时重载 DSH 和桥接；本次不自动启停服务，也不执行真实 QQ/API 联调。
