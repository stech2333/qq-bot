# 统一风格自动学习

最终回答结合 **全局表达风格 + 当前角色卡 + 当前会话的长期记忆**，并服从当前任务的明确要求、事实准确性和原有权限。各群/私聊只分别维护话题兴趣、记忆及既有会话运行状态；不再建立群风格或个人风格档案。

## 学习与应用

- 汇总允许参与且允许积累记忆的会话，只分析真人来源消息；全局风格不从长期事实、摘要或机器人自身输出生成。
- 八类有界特征：语气、措辞、句式、回答结构、接话方式、分段、标点和表情。例如先表达结论后补理由、用具体例子说明、接住话题后补充自己的观点。
- 不复制原句或口头禅，不保存人物身份、经历、观点、私聊事实或自由文本指令。结果仅为预定义枚举；来源标识只用于核验、失效判断和管理端追溯。
- 以北京时间的日期、会话和发言者均衡取样，最多48条。重复粘贴按日期去重，同一人同会话一分钟内最多取一条；不要求必须来自多个群或多个人。
- 跳过转发、媒体、明显引用、代码块、链接、过长文字和隐私过滤未通过的内容。新版记录保留来源类型标记；旧记录缺少这些标记时不用于全局风格，避免把历史转发当作本人表达。
- 可归纳单条回答的组织方式；不把群内相邻消息猜成问答。`replyToBot` 只表示确实引用机器人，缺少上文时不猜测具体回应关系。
- 不将“用户说得短”解释成“希望机器人短答”。正式问题仍需完整解答；闲聊和正式解答共用风格，但按场景选择适当特征，角色身份和个性保留。

## 默认门槛

| 设置 | 默认值 |
| --- | --- |
| 自动学习 / 影响回复 | 均开启；尚未达标时继续原角色表达 |
| 回看窗口 | 720小时（30天） |
| 候选语料 | 至少20次有效发言，覆盖至少3个日期 |
| 单项依据 | 至少3条真实来源，覆盖至少3个日期 |
| 最低置信度 | 0.85，且不低于共用自动研究门槛 |
| 更新间隔 | 至少6小时 |
| 再次分析 | 至少新增10次有效发言 |
| 每日分析 | 最多4次，同时受现有研究总额度约束 |
| 每轮变化 | 最多2个维度，其余维度逐步融合 |
| 版本历史 | 最多20个版本，不含聊天正文 |

置信度是模型给出的筛选分，不是经过校准的正确率。程序另行检查来源、日期、枚举和状态；已有特征变成不同值还需要更新后跨3天的新依据，避免同一批语料被反复解释而漂移。

后台分析使用现有隔离学习会话和配置的模型，不阻塞正常首答、不向QQ发送分析过程。失败同样消耗已预留调用额度；重启、清空风格和删除特征不退还额度。话题和黑话任务保持原有范围与确认规则，私聊材料不会进入群话题或黑话研究。

## 管理入口

侧栏 **统一风格学习**：查看有效语料、当前特征、来源编号与日期、研究状态；调整门槛，独立开关学习和应用；锁定/解锁、人工指定某项、删除、清空、回滚。

同页提供 **回复分条方式（全局）**：自然分条（默认，优先一条，确需时再分）、尽量一条、适度分条。保存后即时用于后续闲聊及正式回答，不需重启；独立于自动学习开关。该设置指导模型组织消息，不强制固定条数、不截断正文。设置保存在原策略文件的 `replyDelivery`，不作为学习特征或会话偏好保存。

- 锁定停止自动更新，有效风格继续应用；回滚后自动锁定。
- 人工指定的维度不会被自动结果覆盖，删除后才恢复该维度的自动学习。
- 删除特征设置该维度的来源截止时间；旧语料不能立即重新激活，回滚也不能绕过截止时间。清空同时移除风格历史，只从此后新消息重新积累。
- 自动特征的来源过期、会话被停用或停止积累后停止应用；不把过期画像无限固定。
- 会话关闭“使用长期记忆与全局风格”后，不为该会话附加全局风格。其他会话继续共用同一份风格。
- 重置、管理操作、政策变化、来源撤销发生在模型等待期间时，旧结果不能写回。文件保存失败保持旧特征不变；损坏记录停止覆盖并显示错误。

文件为 `integrations/qq-bridge/state/global-style.json`，策略保存在原 `bigfatfish-settings.json` 的 `globalStyleLearning`。`/api/bigfatfish/global-style` 仅管理端开放，修改检查版本；QQ会话模型不能调用。原群风格模块、群风格设置、会话风格锁定和注入逻辑已移除；旧数据读取时丢弃风格字段，保留事实、摘要、兴趣及其他会话状态。

## 方案审查与验证

审查重点：群和用户不再产生风格分支；事实不随风格共享；自身输出不能形成循环证据；引用和刷屏不能放大证据；模型自由文本不能进入风格提示；控制开关、删除截止时间和版本需在提交结果时再次检查。

运行 `npm run test:companion` 验证记忆、心情、全局风格及学习调度。`node scripts/check-companion-ui.cjs` 使用本地虚拟数据验证导航、特征依据、设置、锁定、人工值、回滚、删除和文本转义，不调用真实模型或发送QQ消息。

结构和边界测试不能证明表达效果已达到最佳。实际风格需在后续真实对话积累后观察；本次不伪造历史材料，也不提前生成一份冒充“已学会”的风格。
