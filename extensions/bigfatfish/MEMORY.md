# 长期记忆与统一表达风格

最终回答结合全局风格、当前角色卡和当前会话长期记忆。各群聊/私聊分别维护事实、摘要和兴趣话题，不再维护会话风格；统一风格的学习、来源、管理及额度见 [统一风格自动学习](GLOBAL_STYLE.md)。

## 管理入口

桥接控制台侧栏“长期记忆”，选择群聊或私聊后加载。事实键、档案导入、历史和心情模块另见 [心情与记忆增强](COMPANION.md)。

- 搜索、添加、纠正、删除长期事实，调整可信度、重要度与有效期；编辑或清空阶段摘要。
- 关闭“允许积累新记忆”后，暂停该会话的模型记忆写入和对自动学习的贡献；已有记忆仍可使用、删除，管理员仍可纠正。
- 关闭“使用长期记忆与全局风格”后，该会话不注入长期事实、摘要、统一风格及心情提示；存量数据保留，近期聊天上下文正常使用。
- 风格统一在“统一风格学习”中管理，不再提供群风格设置、个人风格设置或会话风格锁定。明确偏好仍可作为本会话事实保存，不会直接改成全局指令。
- 管理接口需控制台身份，不向QQ会话模型暴露；未新增QQ聊天管理命令。

## 存储与恢复

沿用 `integrations/qq-bridge/state/social-v2.json` 的会话隔离与原子保存。`memoryControl` 保存积累和使用开关，`memoryRevision` 检查管理操作版本，防止旧页面覆盖新内容。

事实保留ID、内容、来源、可信度、重要度、时间、有效期及事实键等字段。旧版 `style`、`groupStyle`、`styleResearch` 和事实中的 `styleEvidence` 不再参与运行，绑定会话时移除；不把旧群风格直接合并为“已学会”的统一风格。

记忆修改前在 `state/memory-backups/` 保存当前会话快照，每个会话最多5份，不保存令牌或完整聊天流水。写入失败回滚内存并返回失败。历史备份可能仍含最近删除的内容，随之后五次修改轮换，不保证永久抹除。

所有事实、摘要及兴趣以真实 `group:群号` / `private:QQ号` 分区。全局风格只包含有界表达特征，不传递其他群或私聊的事实。既有事实、摘要、会话映射和QQ收藏表情保留。

## 定向验证

`npm run test:companion` 使用隔离文件和模拟模型结果，验证记忆、心情、统一风格与学习调度。回复链路另以 `runtime.test.mjs`、`chat-delivery.test.mjs` 验证；浏览器控件检查使用 `node scripts/check-companion-ui.cjs`，不发送QQ消息。
